# Security policy

Please do not disclose a suspected vulnerability in a public issue. Use [GitHub private vulnerability reporting](https://github.com/KlowzyZ/OZFA-Quick-Formatter/security/advisories/new) and include the affected version, impact, and safe reproduction details.

Only the latest stable release is actively supported. Do not test a report against an important disk, and do not include credentials, personal data, or unrelated disk contents.
